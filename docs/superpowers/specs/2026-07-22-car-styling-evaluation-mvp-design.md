# 汽车造型设计数据评价系统 — MVP 设计文档

> 日期: 2026-07-22 | 状态: Approved

## 1. 概述

为汽车设计师提供一个基于 Streamlit + Plotly 的 Web 工具，用于对"在研车型"的造型设计参数进行量化评价。系统通过五步法（比例、姿态、型面、细节品质、工程平衡）和 Z-score 统计方法，将主观设计判断转化为 0-10 标准分，并与竞品数据库进行宏观+微观双层对比。

## 2. 技术选型

| 依赖 | 用途 |
|------|------|
| `streamlit` | Web 框架，页面渲染 + 交互组件 |
| `pandas` | 竞品数据库管理 + 统计计算 |
| `numpy` | 数值计算（mean, std, Z-score） |
| `plotly` | 雷达图 + 正态分布曲线图 |
| `scipy.stats` | 正态分布 PDF 计算 |

## 3. 数据模型

### 3.1 竞品数据库

10 款车型，每车 16 个字段：

**基础字段：** 车型、类型（轿车/SUV/猎装）、风格（运动/豪华/科技）、车高(mm)、轮胎高度(mm)、轴距(mm)、车长(mm)

**底层子参数 (10个, 归于5维度)：**

| 维度 | 子参数 | 单位 |
|------|--------|------|
| 比例 | 轮高车高比 = 轮胎高度/车高×100% | % |
| 比例 | 轴长比 = 轴距/车长×100% | % |
| 姿态 | 窗身比 | % |
| 姿态 | 窗台线水平夹角 | ° |
| 型面 | 曲率平滑度评分 | 0-100 |
| 型面 | 特征线连续性评分 | 0-100 |
| 细节品质 | 家族特征匹配度 | 0-100 |
| 细节品质 | 间隙段差综合值 | mm |
| 工程平衡 | 头部空间余量 | mm |
| 工程平衡 | 前向视野下沿角 | ° |

**布尔字段：** 销量>5000

### 3.2 车型列表

小米SU7, 汉EV, 问界M5, Model 3, ET5, 极氪001, 理想L7, P7, 阿维塔12, 海豹EV

参数值遵循真实汽车工程常识（具体数值见数据模型设计页面）。

## 5. UI 布局

### 5.1 左侧边栏 (Sidebar)
- **在研车型名称**：文本输入
- **造型风格**：下拉选择（运动/豪华/科技）
- **10个子参数滑块/输入框**，分5组展示
- **对标竞品池**：多选框（默认全选10款）

### 5.2 主页面上半部 — 宏观总览
- **Plotly 雷达图**：5个顶点（比例/姿态/型面/细节品质/工程平衡）
- 红色填充区域 = 在研车型得分
- 蓝色轮廓线 = 竞品均值得分
- 右上角评分摘要表

### 5.3 主页面下半部 — 微观详情
- `st.tabs` 5个Tab页切换各维度
- 每个Tab内绘制该维度下子参数的**正态分布钟形曲线**
- 红色竖线标注在研车型位置
- 绿色虚线标注"销量>5000"爆款均值
- 曲线使用 `scipy.stats.norm.pdf` 拟合
